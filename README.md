# Ismail 3000

Site vitrine d'Ismail Haiber, ingénieur QA Full-Stack. Site statique hébergé sur Netlify.

- `index.html` : le site (FR/EN)
- `data.json` : tout le contenu, modifiable depuis l'admin
- `admin/` : interface d'administration (Decap CMS), accessible via `/admin` avec une connexion GitHub
- `uploads/` : photos et fichiers envoyés depuis l'admin

Chaque modification publiée depuis l'admin crée un commit sur `main`, et Netlify redéploie le site automatiquement.
